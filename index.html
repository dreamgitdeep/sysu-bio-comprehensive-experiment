多设备同步工作流

  1. 换到新电脑：安装 Git 后执行 git clone https://github.com/dreamgitdeep/sysu-bio-comprehensive-experiment.git
  2. 开始工作前：先 git pull 拉取最新版本，避免覆盖他人改动
  3. 本地预览：双击 preview.cmd（或执行 python -m http.server 8000）
  4. 改完后提交：sync.cmd "本次改了什么"，自动完成 add / commit / push
  5. 约 1 分钟后：GitHub Pages 自动更新，在线链接即可看到最新版本
